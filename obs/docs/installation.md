# Installation

## Stable release

To install loteria, run this command in your terminal:

```sh
uv add loteria
```

Or if you prefer to use `pip`:

```sh
pip install loteria
```

## From source

The source files for loteria can be downloaded from the [Github repo](https://github.com/philpot/loteria).

You can either clone the public repository:

```sh
git clone git://github.com/philpot/loteria
```

Or download the [tarball](https://github.com/philpot/loteria/tarball/master):

```sh
curl -OJL https://github.com/philpot/loteria/tarball/master
```

Once you have a copy of the source, you can install it with:

```sh
cd loteria
uv pip install .
```
